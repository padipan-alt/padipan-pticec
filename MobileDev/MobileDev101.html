MobileDev 101
วิวัฒนาการ ระบบปฏิบัติการ ประเภทแอป จริยธรรม & ความปลอดภัย แหล่งเรียนรู้

รายวิชา 21910-2017 การพัฒนาโปรแกรมบนอุปกรณ์พกพาเบื้องต้น ครูปฎิภาณ พานทอง

หน่วยที่ 1: ความรู้เบื้องต้นเกี่ยวกับอุปกรณ์พกพาและแอปพลิเคชัน

เรียนรู้จุดเริ่มต้นของอุปกรณ์พกพา ระบบปฏิบัติการที่ขับเคลื่อนโลกยุคใหม่ รูปแบบของแอปพลิเคชัน และข้อควรระวังในการใช้งาน

วิวัฒนาการและประเภทของอุปกรณ์พกพา

จากยุคแอนะล็อกที่โทรศัพท์มีขนาดเท่ากระติกน้ำ พัฒนามาสู่ยุคดิจิทัลที่คอมพิวเตอร์ประสิทธิภาพสูงถูกย่อส่วนให้อยู่ในมือและบนข้อมือของเรา

Feature Phone & PDA

ยุค 2G-3G เน้นการโทรและ SMS เป็นหลัก โทรศัพท์บางรุ่นเริ่มมีปุ่มกด QWERTY ส่วน PDA (Personal Digital Assistant) เริ่มมีการใช้ปากกา Stylus สำหรับจดบันทึกและจัดการตารางเวลา ถือเป็นต้นแบบของสมาร์ทโฟน

สมาร์ทโฟน (Smartphone)

จุดเปลี่ยนสำคัญเกิดขึ้นเมื่อมีการเปิดตัว iPhone ในปี 2007 ที่ใช้หน้าจอสัมผัสแบบ Multi-touch สมาร์ทโฟนกลายเป็นศูนย์กลางการใช้ชีวิต มี OS ของตัวเอง กล้องคุณภาพสูง และระบบสโตร์สำหรับโหลดแอป

แท็บเล็ต (Tablet)

อุปกรณ์หน้าจอ 7-12 นิ้ว อุดช่องโหว่ระหว่างมือถือและแล็ปท็อป ปัจจุบันแท็บเล็ตมีประสิทธิภาพสูงมากจนสามารถใช้แทนคอมพิวเตอร์ในการตัดต่อวิดีโอ วาดภาพ หรือทำงานเอกสารได้อย่างสมบูรณ์แบบ

อุปกรณ์สวมใส่ (Wearables)

Smartwatch และ Smartband เป็นส่วนต่อขยายของมือถือ เน้นการแจ้งเตือน การติดตามสุขภาพ (วัดชีพจร, การนอน) และการออกกำลังกาย มีแอปพลิเคชันขนาดเล็ก (Micro-apps) ที่ทำงานเฉพาะทาง

ระบบปฏิบัติการ (Operating System)

ซอฟต์แวร์ระบบที่เป็นตัวกลางระหว่างฮาร์ดแวร์และผู้ใช้งาน ในโลกมือถือมี 2 ค่ายยักษ์ใหญ่ที่ครองตลาด

Android

พัฒนาโดย Google

  • เป็นระบบเปิด (Open Source) ดัดแปลงได้
  • ครองส่วนแบ่งการตลาดสูงที่สุดในโลก (ราว 70%)
  • รองรับอุปกรณ์ตั้งแต่ราคาประหยัดถึงระดับพรีเมียม
  • ใช้ภาษา Java/Kotlin ในการพัฒนา Native App
Android Developers

iOS

พัฒนาโดย Apple

  • ระบบปิด (Closed System) ใช้เฉพาะเครื่อง Apple
  • ขึ้นชื่อเรื่องความปลอดภัยและการอัปเดตที่ยาวนาน
  • ผู้ใช้มีกำลังซื้อสูง เหมาะกับการทำแอปเชิงพาณิชย์
  • ใช้ภาษา Swift / Objective-C ในการพัฒนา
Apple Developer

เกร็ดความรู้: ในอดีตเคยมีระบบปฏิบัติการอื่นๆ ที่ได้รับความนิยม เช่น Symbian (ครองตลาดโดย Nokia), BlackBerry OS (เด่นเรื่องอีเมลและคีย์บอร์ด) และ Windows Phone (ดีไซน์ Live Tiles ของ Microsoft) แต่ปัจจุบันยุติการพัฒนาไปแล้วเนื่องจากไม่สามารถแข่งขันกับ Ecosystem ของ iOS และ Android ได้

ประเภทของแอปพลิเคชัน

สถาปัตยกรรมในการสร้างแอปพลิเคชันแบ่งออกเป็น 3 ประเภทหลักๆ ซึ่งมีข้อดีและข้อเสียแตกต่างกันไป

Native App

แอปที่พัฒนาขึ้นมาเพื่อระบบปฏิบัติการนั้นๆ โดยเฉพาะ ใช้เครื่องมือและภาษาที่เจ้าของ OS กำหนด (เช่น Xcode สำหรับ iOS, Android Studio สำหรับ Android)

ดึงศักยภาพเครื่องได้ 100% เหมาะกับเกมกราฟิกสูง หรือแอปที่ซับซ้อน ต้องใช้ทีมนักพัฒนา 2 ทีม (iOS / Android)

Web App & PWA

พัฒนาด้วย HTML, CSS, JavaScript เปิดใช้งานผ่านบราวเซอร์ ปัจจุบันมีเทคโนโลยี PWA (Progressive Web App) ที่ทำให้เว็บแอปทำงานได้คล้ายแอปจริง (เช่น ซ่อนแถบ URL, ส่งแจ้งเตือนได้, ใช้งานออฟไลน์ได้บางส่วน)

ไม่ต้องลงผ่าน Store (ข้ามข้อจำกัดการอนุมัติ) พัฒนาและอัปเดตเวอร์ชันได้ทันที ข้อจำกัดการเข้าถึง Bluetooth, NFC, Background Tasks

Hybrid / Cross-Platform App

เทรนด์ยอดฮิตในปัจจุบัน เขียนโค้ดชุดเดียว (Single Codebase) แปลงรันได้ทั้ง iOS/Android เฟรมเวิร์กที่นิยมระดับโลก ได้แก่ Flutter (ภาษา Dart ของ Google) และ React Native (JavaScript ของ Meta/Facebook) ส่วนเครื่องมือสำหรับผู้เริ่มต้นเช่น Thunkable

ลดต้นทุนค่าแรงและระยะเวลาพัฒนาลง 30-50% UI มีความสม่ำเสมอในทุกแพลตฟอร์ม อาจเจอปัญหาเมื่อ OS อัปเดตฟีเจอร์ใหม่ (ต้องรอ Framework อัปเดตตาม)

จริยธรรมและความปลอดภัย

ในฐานะนักพัฒนาและผู้ใช้งาน การตระหนักถึงความปลอดภัยและสิทธิส่วนบุคคลเป็นสิ่งที่ขาดไม่ได้

จริยธรรมของนักพัฒนา

  • พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA): ต้องมีการขอความยินยอม (Consent) ก่อนเก็บข้อมูลส่วนตัว และให้สิทธิ์ผู้ใช้ในการลบหรือขอข้อมูลคืนได้เสมอ
  • เคารพทรัพย์สินทางปัญญา: ไม่ละเมิดลิขสิทธิ์โค้ด (Software Piracy), ไอคอน, ภาพกราฟิก, หรือแม้แต่เสียงประกอบจากแอปอื่นๆ
  • ความปลอดภัยในโค้ด (Secure Coding): ไม่ฝังรหัสผ่านลงในซอร์สโค้ดโดยตรง (Hardcode) และมีการเข้ารหัสข้อมูลสำคัญก่อนส่งผ่านอินเทอร์เน็ต

ความปลอดภัยสำหรับผู้ใช้งาน (ผู้โหลดแอป)

  • ตรวจสอบการขอสิทธิ์ (Permissions): ระวังแอปปลอมแปลงที่ขอสิทธิ์เกินความจำเป็น เช่น แอปเครื่องคิดเลขขอสิทธิ์เข้าถึงข้อความ (SMS) หรือแกลลอรี่ภาพ
  • ระวังลิงก์แปลกปลอม (Phishing): ไม่กดลิงก์จาก SMS หรือ Line ที่เชิญชวนให้โหลดแอปพลิเคชันนอกสโตร์ เพราะมักเป็นมัลแวร์ดูดเงิน
  • อัปเดตระบบสม่ำเสมอ: หมั่นอัปเดต OS และแอปพลิเคชันเวอร์ชันล่าสุดเสมอ เพื่ออุดช่องโหว่ (Patch) ทางด้านความปลอดภัย

แหล่งเรียนรู้และเว็บไซต์ที่เกี่ยวข้อง

ศึกษาเพิ่มเติมเกี่ยวกับการพัฒนาแอปพลิเคชันด้วยเครื่องมือต่างๆ และข่าวสารทางเทคโนโลยี

MIT App Inventor

เครื่องมือสร้างแอปแบบบล็อก (Block-based) เหมาะสำหรับผู้เริ่มต้น

Thunkable

สร้างแอปพลิเคชันแบบ Cross-platform (iOS/Android) แบบไม่ใช้โค้ด

Flutter

เฟรมเวิร์กยอดนิยมจาก Google สำหรับพัฒนา Cross-platform App

PDPA Thailand
