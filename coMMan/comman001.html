การบำรุงรักษาคอมพิวเตอร์ด้วย Control Panel

และการแก้ปัญหาคลาสสิก "Disk 100%" บน Windows 10 ด้วยตนเอง

🧑‍💻 สำหรับผู้ใช้งานทั่วไป ⏱️ เรียนรู้ใน 10 นาที

🎯 วัตถุประสงค์การเรียนรู้

  • เพื่อให้เข้าใจบทบาทของ Control Panel ในการบำรุงรักษาระบบ
  • สามารถใช้เครื่องมือพื้นฐานเพื่อเพิ่มพื้นที่และจัดการฮาร์ดแวร์ได้
  • สามารถแก้ไขปัญหาคอมพิวเตอร์ช้าจากอาการ "Disk 100%" เบื้องต้นได้ด้วยตนเอง
🎛️

1. รู้จัก Control Panel ศูนย์กลางการจัดการ

Control Panel คืออะไร?

คือ หน้าต่างศูนย์รวมเครื่องมือตั้งค่าต่างๆ ของระบบปฏิบัติการ Windows ช่วยให้เราสามารถจัดการฮาร์ดแวร์ ซอฟต์แวร์ และความปลอดภัยให้อยู่ในสภาพพร้อมใช้งานเสมอ

ทำไมถึงต้องบำรุงรักษาคอมพิวเตอร์?

  • 🚀 เพิ่มความเร็ว เพื่อให้เครื่องทำงานได้รวดเร็วเต็มประสิทธิภาพ ไม่หน่วง ไม่ค้าง
  • 🔋 ยืดอายุอุปกรณ์ ช่วยถนอมและยืดอายุการใช้งานของฮาร์ดดิสก์ แบตเตอรี่ และชิ้นส่วนอื่นๆ
  • 🛡️ ปลอดภัยเสมอ อุดช่องโหว่ด้านความปลอดภัยและลดปัญหาที่อาจเกิดจากไวรัส
💾

2. การจัดการโปรแกรมและพื้นที่

🗑️ การถอนการติดตั้งโปรแกรม

Programs and Features

Control Panel > Programs and Features

ประโยชน์: เลือกลบโปรแกรมหรือเกมที่ไม่ได้ใช้ ช่วยคืนพื้นที่ว่างให้ไดรฟ์ (โดยเฉพาะไดรฟ์ C:) และลดการใช้ CPU/RAM เบื้องหลัง

🧹 การลบไฟล์ขยะ

Disk Cleanup

Windows Tools > Disk Cleanup

ประโยชน์: ลบไฟล์ชั่วคราว (Temp files) และไฟล์แคชที่ระบบสร้างขึ้นแต่ไม่ได้ใช้แล้ว ป้องกันไดรฟ์เต็ม

🚨

3. กรณีศึกษา: อาการ Disk 100%

อาการคืออะไร?

คอมพิวเตอร์มีอาการกระตุก ค้าง สลับหน้าจอช้า เมื่อเปิด Task Manager (กด Ctrl+Shift+Esc) จะพบว่าช่อง Disk ขึ้นแถบสีแดงและวิ่งอยู่ที่ 100% ตลอดเวลา

สาเหตุหลัก

มักเกิดจากเซอร์วิสของ Windows 10 บางตัวที่พยายามอ่าน/เขียนข้อมูลเบื้องหลังตลอดเวลา ซึ่งส่งผลกระทบหนักมากหากใช้ฮาร์ดดิสก์แบบเก่า (HDD) หรือแม้แต่สเปคเริ่มต้นที่ใช้ SSD ก็อาจพบเจอปัญหานี้ได้

🛠️

4. วิธีแก้ปัญหา Disk 100% ทีละขั้นตอน

1

ปิดการทำงานของ SysMain (Superfetch)

  1. เปิด Control Panel (ปรับ View by เป็น Large icons) > Administrative Tools
  2. ดับเบิลคลิกที่ Services
  3. หาชื่อเซอร์วิส SysMain > คลิกขวาเลือก Properties
  4. ตรง Startup type เปลี่ยนเป็น Disabled > กดปุ่ม Stop > กด OK
2

ปิดระบบค้นหาอัตโนมัติ (Windows Search)

  1. ในหน้าต่าง Services เดิม
  2. หาชื่อเซอร์วิส Windows Search > คลิกขวาเลือก Properties
  3. เปลี่ยน Startup type เป็น Disabled > กดปุ่ม Stop > กด OK
3

ปรับพลังงานเป็น High Performance

  1. กลับไปที่ Control Panel > เลือก Power Options
  2. เลือกแผนพลังงานเป็น High Performance เพื่อให้เมนบอร์ดจ่ายไฟให้ฮาร์ดแวร์เต็มที่
⚠️

⚠️ ข้อควรระวัง! คำเตือนสำหรับผู้ใช้ SSD

ห้ามจัดเรียงข้อมูล (Defragment) กับไดรฟ์ SSD เด็ดขาด!

  • เครื่องมือ Defragment and Optimize Drives มีไว้สำหรับฮาร์ดดิสก์จานหมุน (HDD) แบบเก่าเท่านั้น
  • ทำไมห้ามทำ? การทำ Defrag ไม่ได้ช่วยแก้ Disk 100% แต่จะทำให้เซลล์หน่วยความจำของ SSD ถูกเขียนทับซ้ำๆ จนเสื่อมสภาพและอายุการใช้งานสั้นลงอย่างรวดเร็ว
  • ระบบจัดการเอง: Windows รุ่นใหม่จะใช้คำสั่ง TRIM บำรุงรักษา SSD โดยอัตโนมัติอยู่แล้ว

สรุปบทเรียน

Control Panel เป็นจุดเริ่มต้นที่ดีในการเช็กความเรียบร้อยของเครื่อง อาการ Disk 100% ส่วนใหญ่แก้ได้โดยการปิดเซอร์วิสที่ไม่จำเป็น และที่สำคัญรู้จักอุปกรณ์ของตัวเอง ถ้าใช้ SSD ห้ามสั่ง Defragment เด็ดขาด
