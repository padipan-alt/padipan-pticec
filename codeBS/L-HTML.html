พื้นฐานภาษา HTML

HTML (Hypertext Markup Language) คือภาษาคอมพิวเตอร์พื้นฐานที่ใช้ในการสร้างและจัดโครงสร้างของหน้าเว็บไซต์ โดยจะใช้ "แท็ก" (Tags) ในการกำหนดว่าส่วนต่างๆ ของหน้าเว็บคืออะไร เช่น หัวข้อ ย่อหน้า รูปภาพ หรือลิงก์

การเขียน HTML มักจะเขียนเป็นคู่เสมอ คือมี แท็กเปิด <...> และ แท็กปิด </...> (โดยแท็กปิดจะมีเครื่องหมายทับ / อยู่ด้านหน้า)

1 โครงสร้างพื้นฐานของ HTML

ทุกหน้าเว็บที่เขียนด้วย HTML จะต้องมีโครงสร้างหลักแบบนี้เสมอ:

index.html 
<!DOCTYPE html>
<html>
<head>
    <title>ชื่อหน้าเว็บ (จะแสดงที่แท็บเบราว์เซอร์)</title>
</head>
<body>
    <h1>สวัสดีชาวโลก!</h1>
    <p>นี่คือหน้าเว็บหน้าแรกของฉัน</p>
</body>
</html>
  • <!DOCTYPE html> : เป็นการบอกเบราว์เซอร์ว่าไฟล์นี้เป็น HTML5
  • <html> : แท็กครอบคลุมเนื้อหาทั้งหมดของหน้าเว็บ
  • <head> : ส่วนเก็บข้อมูลของหน้าเว็บ เช่น ชื่อเรื่อง (Title) หรือการเชื่อมโยงไฟล์ CSS
  • <body> : ส่วนที่แสดงผลเนื้อหาทั้งหมดที่ผู้ใช้งานจะมองเห็นบนหน้าเว็บ

2 แท็ก (Tags) ที่ใช้บ่อยในการเขียนเว็บ

นี่คือแท็กพื้นฐานที่คุณจะได้ใช้บ่อยที่สุดในการเริ่มต้นเขียน HTML:

หัวข้อ (Headings)

ใช้ <h1> ถึง <h6> โดย h1 ใหญ่สุด

<h1>หัวข้อหลัก</h1>
<h2>หัวข้อย่อย</h2>

ย่อหน้า (Paragraph)

ใช้เขียนข้อความทั่วไป

<p>นี่คือข้อความในย่อหน้าแรก</p>

ลิงก์ (Links)

สร้างจุดคลิกด้วย <a> คู่กับ href

<a href="https://google.com">ไปที่ Google</a>

รูปภาพ (Images)

แท็กเดี่ยว <img> คู่กับ src

<img src="pic.jpg" alt="คำอธิบาย">

รายการ (Lists)

หัวข้อย่อยแบบจุด <ul> หรือแบบตัวเลข <ol>

<ul>
    <li>รายการที่ 1</li>
    <li>รายการที่ 2</li>
</ul>

แนะนำคอร์สเรียนอื่นๆ

วิทยาการคำนวณ

เรียนรู้กระบวนการคิดเชิงคำนวณ การแก้ปัญหาอย่างเป็นระบบ และทักษะดิจิทัลเบื้องต้น

กำลังเรียน

การสร้างเว็บไซต์ด้วย HTML

ปูพื้นฐานการเขียนโค้ดเว็บไซต์ ตั้งแต่โครงสร้าง HTML ไปจนถึงการตกแต่งความสวยงาม

การออกแบบกราฟิกเบื้องต้น

เรียนรู้หลักการจัดวาง การใช้สี และเครื่องมือพื้นฐานในการสร้างสรรค์งานกราฟิกที่น่าสนใจ
